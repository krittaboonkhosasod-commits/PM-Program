สรุปผล

📖 คู่มือการใช้งาน PM Program

1. เริ่มต้นใช้งาน
  1. หน้าแรกกรอก ชื่อไซต์ / อาคาร และ ปี แล้วกด “สร้างฐานข้อมูลใหม่” โปรแกรมจะสร้างไฟล์ Excel (.xlsx) เปล่าที่มีชีตสรุปผล แผนประจำปี และชีตรายเดือน 12 ชีต
  2. มีไฟล์ฐานข้อมูลอยู่แล้ว ให้กด “เปิดฐานข้อมูลที่มีอยู่” แล้วเลือกไฟล์ .xlsx
  3. ถ้าเชื่อม Google Sheet ไว้แล้วและข้อมูลอยู่ในชีต ให้กด “ดึงข้อมูลจาก Google Sheet” ไม่ต้องมีไฟล์ Excel (ดูหัวข้อ 8)
  4. ครั้งต่อไปที่เปิดหน้าเว็บหรือรีเฟรช โปรแกรมจะเปิดข้อมูลล่าสุดให้เอง (จำไว้ในเบราว์เซอร์ของเครื่องนี้)

ไฟล์ Excel ที่โปรแกรมสร้างและบันทึกยังเป็นรูปแบบรายงานเดิมทุกอย่าง (สูตร สี ตารางสรุป) นำไปพิมพ์หรือส่งต่อได้ตามปกติ

2. เมนูและหน้าจอ
  • สรุปผล ภาพรวมทั้งปี กราฟรายเดือน ตารางสรุป และช่องผู้ลงนาม
  • แผนรายเดือน ตารางงาน PM รายวันของแต่ละเดือน ใช้บันทึกแผนและงานที่ทำจริง
  • แผนประจำปี ตารางวางแผนรายสัปดาห์ (W1–W5 ของแต่ละเดือน) ทั้งปี
  • คู่มือ หน้านี้ · ตั้งค่า ไฟล์ฐานข้อมูล การเชื่อม Google Sheet และข้อมูลโครงการ
  • มุมขวาบนมี 2 ป้าย: ป้ายสถานะ Google Sheet (ถ้าเชื่อมไว้) และป้ายชื่อไฟล์ จุดแดง = มีการแก้ไขที่ยังไม่ได้บันทึกลงไฟล์ Excel กดป้ายเพื่อไปหน้าตั้งค่า
  • บนมือถือเมนูอยู่แถบด้านล่างของหน้าจอ
3. หน้าสรุปผล
  • วงกลมแสดงผลลัพธ์ทั้งปี = งานที่ทำเสร็จ ÷ งานตามแผน เป้าหมาย 100%
  • กราฟแท่งรายเดือน: เขียว = ถึงเป้า 100% · เหลือง = 60–99% · แดง = ต่ำกว่า 60% · เทา = เดือนที่ไม่มีแผน
  • ตารางสรุปแสดงงาน PM ทั้งหมด / เสร็จแล้ว / ยังไม่เสร็จ / ร้อยละ รายเดือนและรวมทั้งปี คำนวณให้อัตโนมัติจากแผนรายเดือน
  • ช่อง ผู้ลงนาม (จัดทำ / ตรวจสอบ / อนุมัติ) พิมพ์ชื่อได้เลย และจะถูกบันทึกลงรายงานด้วย
  • ปุ่ม “พิมพ์” พิมพ์รายงานสรุปเป็นกระดาษ A4 แนวนอน
4. แผนรายเดือน: บันทึกแผนและงานที่ทำจริง
  1. เลือกเดือนจากแถบด้านบน จุดใต้ชื่อเดือน: เขียว = เสร็จครบ · เหลือง = ทำแล้วบางส่วน · เทา = มีแผนแต่ยังไม่ทำ
  2. คลิกช่องวันที่ ของเครื่องจักรที่ต้องการ จะมีกล่องเลือกรหัสงานขึ้นมา (ดูตารางรหัสในหัวข้อ 5) เลือกรหัส เช่น D W M Q Y
  3. เมื่อทำงานเสร็จ กด “ทำจริง / ตรวจแล้ว (Actual, a)” ช่องจะเปลี่ยนเป็นสีเขียว เช่น Qa = แผนรายไตรมาส + ทำแล้ว (นับทั้ง Plan และ Actual) หรือกด “ทำจริง” อย่างเดียวโดยไม่เลือกรหัสก็ได้ (ช่องจะเป็น A)
  4. กด “ล้างช่อง” เพื่อลบ กด “เสร็จ” เพื่อปิดกล่อง การแก้ไขบันทึกทันที ไม่มีปุ่มบันทึกต่อช่อง
  5. คอลัมน์ Plan / Actual / % ท้ายแถวและป้ายด้านบนตารางคำนวณให้เอง ส่วนวันที่ไม่มีในเดือนนั้นจะเป็นสีจาง

จัดการรายการเครื่องจักร

  • “+ เครื่องจักร” เพิ่มรายการ กรอกชื่อ (บังคับ) ที่ตั้ง ผู้ดำเนินการ รอบ (Period) และหมายเหตุ ติ๊ก “เพิ่มเครื่องจักรนี้ในทุกเดือนด้วย” ถ้าต้องการให้ขึ้นครบ 12 เดือน
  • “+ หัวข้อระบบ” เพิ่มแถวหัวข้อเพื่อแบ่งกลุ่มเครื่องจักร
  • ไอคอนดินสอ = แก้ไข (ติ๊กได้ว่าแก้ทุกเดือนด้วย) · ไอคอนถังขยะ = ลบแถวนั้น เฉพาะเดือนที่เปิดอยู่
  • ช่องค้นหาหาได้จากชื่อเครื่องจักร ที่ตั้ง หรือผู้ดำเนินการ
5. ตารางรหัสงาน
  • D รายวัน · W รายสัปดาห์ · M รายเดือน · 2M ทุก 2 เดือน · 3M ทุก 3 เดือน
  • Q รายไตรมาส · 6M / S ทุก 6 เดือน · Y รายปี
  • AD ตามความจำเป็น (As Required) · O งานวางแผน · P ตามรอบ
  • A / a ทำจริง / ตรวจแล้ว (Actual) ใช้ร่วมกับรหัสแผน เช่น Ma, Qa

กดลิงก์ “รหัสทั้งหมด” ที่แถบอธิบายเหนือตารางเพื่อดูรายการเต็มได้ทุกเมื่อ

6. แผนประจำปี
  • แต่ละเดือนแบ่งเป็นสัปดาห์ W1–W4/W5 คลิกช่องสัปดาห์เพื่อเลือกรหัสแผน (หน้านี้ไม่มีปุ่ม Actual)
  • คอลัมน์ Plan ท้ายแถวนับจำนวนสัปดาห์ที่วางแผนไว้ทั้งปี
  • เพิ่ม / แก้ไข / ลบเครื่องจักร และหัวข้อระบบ ใช้ปุ่มเดียวกับหน้าแผนรายเดือน มีช่อง Machine code เพิ่มเข้ามา
7. บันทึกลงไฟล์ Excel
  • ไปที่ ตั้งค่า → “บันทึก” (หรือกด Ctrl + S บน Mac ใช้ Cmd + S) เขียนการแก้ไขลงไฟล์เดิม “บันทึกเป็น…” สร้างไฟล์ใหม่ไม่ทับไฟล์เดิม
  • บันทึกอัตโนมัติ ใช้ได้เมื่อเปิดไฟล์ด้วยปุ่ม “เปิดไฟล์” ใน Chrome หรือ Edge โปรแกรมจะบันทึกลงไฟล์เองหลังแก้ไข 3 วินาที
  • เบราว์เซอร์อื่น (เช่น Safari, Firefox) การบันทึกจะดาวน์โหลดเป็นไฟล์ใหม่ทุกครั้ง
  • ถ้าเชื่อม Google Sheet ไว้ ข้อมูลจะอยู่ในชีตอยู่แล้ว ไฟล์ Excel ใช้สำหรับพิมพ์ ส่งรายงาน หรือสำรองข้อมูล เมื่อต้องการไฟล์ที่ตรงกับข้อมูลล่าสุดให้กด “บันทึก”
8. เชื่อมต่อ Google Sheet (ซิงค์ข้อมูล)

เมื่อตั้งค่าแล้ว ทุกการแก้ไขจะถูกส่งขึ้น Google Sheet อัตโนมัติ (แท็บ PM_Data ในชีตของคุณ) และเครื่องอื่นที่ใช้ชีตเดียวกันจะเห็นข้อมูลชุดเดียวกัน

  1. สร้าง Apps Script ตามหัวข้อ 9 (ทำครั้งเดียวต่อ 1 ชีต)
  2. เปิด ตั้งค่า → ส่วน “เชื่อมต่อ Google Sheet” วาง Web app URL (ลงท้าย /exec) → “ทดสอบ” → “บันทึก”
  3. โปรแกรมจะดูว่าชีตกับเครื่องนี้ใครมีข้อมูล แล้วจัดการให้: ชีตว่าง = ส่งข้อมูลในเครื่องขึ้นไป · เครื่องยังไม่มีฐานข้อมูล = สร้างจากข้อมูลในชีตให้เอง · มีทั้งสองฝั่ง = ถามว่าจะใช้ข้อมูลฝั่งไหน

ใช้งานบนเครื่องอื่น

  • เปิดโปรแกรม → ตั้งค่า → วาง URL (และ TOKEN ถ้ามี) → บันทึก ระบบจะสร้างฐานข้อมูลจากชีตให้ ไม่ต้องเปิดไฟล์ Excel
  • เครื่องเดิมจะรับข้อมูลที่เครื่องอื่นแก้ ทุก 1 นาที หรือเมื่อกลับมาเปิดหน้าเว็บ
  • ออฟไลน์ก็ใช้งานได้ ข้อมูลจะถูกส่งขึ้นชีตเมื่อกลับมาออนไลน์

ปุ่มในหน้าตั้งค่า

  • ส่งข้อมูลในเครื่องขึ้นชีต เขียนทับข้อมูลทั้งหมดในชีตด้วยข้อมูลของเครื่องนี้
  • ดึงข้อมูลจากชีต เอาข้อมูลในชีตมาแทนที่ข้อมูลในเครื่องนี้
  • ยกเลิกการเชื่อมต่อ กลับไปเก็บข้อมูลในเครื่องนี้อย่างเดียว ข้อมูลในชีตยังอยู่

ป้ายสถานะมุมขวาบน: ☁ ซิงค์แล้ว = เรียบร้อย · ● รอบันทึก / ⟳ = กำลังส่งหรือโหลดข้อมูล · ⚠ = ส่งไม่ได้ ข้อมูลเก็บในเครื่องไว้ก่อนและจะส่งซ้ำเอง ตรวจอินเทอร์เน็ตหรือการตั้งค่า

ข้อควรระวัง: 1 Google Sheet = 1 ฐานข้อมูล ถ้าดูแลหลายไซต์ให้ใช้ชีตแยกกัน (แต่ละชีตมี Apps Script และ URL ของตัวเอง) · ถ้า 2 คนแก้แถวเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังจะเป็นฉบับที่เหลืออยู่ · ไม่ควรแก้ข้อมูลในแท็บ PM_Data ตรง ๆ ถ้าแก้แล้วให้กด “ดึงข้อมูลจากชีต” ในโปรแกรม · ใครมีลิงก์ /exec (และ TOKEN) ก็อ่านและเขียนข้อมูลได้ จึงควรเก็บลิงก์เป็นความลับ และตั้ง TOKEN

9. ตั้งค่า Google Sheet ทีละขั้น (มีรูปประกอบ + โค้ด Code.gs)

ทำตามทีละขั้น ใช้เวลาประมาณ 5–10 นาที ไม่ต้องเขียนโค้ดเอง แค่คัดลอกแล้ววาง แตะที่รูปจริงเพื่อดูภาพขยาย (ภาพวาดในขั้นตอนที่ 1, 5 และ 8 เป็นภาพจำลอง หน้าจอจริงอาจต่างเล็กน้อย)

1

เปิด Apps Script จาก Google Sheet
เปิดชีตที่จะใช้เก็บข้อมูล (สร้างชีตเปล่าใหม่ก็ได้) แล้วไปที่เมนู ส่วนขยาย (จุด 1) → Apps Script (จุด 2) ต้องเปิดจากเมนูในชีตนี้เท่านั้น เพื่อให้โค้ดผูกกับชีตที่ถูกต้อง

2

คัดลอกโค้ด
กดปุ่มด้านล่าง (ไม่ต้องอ่านหรือแก้โค้ด)

3

วางโค้ดและบันทึก
ในหน้า Apps Script คลิกในช่องโค้ด กด Ctrl+A แล้ว Delete เพื่อลบโค้ดเดิมทั้งหมด จากนั้นกด Ctrl+V เพื่อวาง แล้วกดไอคอนบันทึก 💾 จนข้อความ “การเปลี่ยนแปลงที่ไม่ได้บันทึก” หายไป (บน Mac ใช้ Cmd แทน Ctrl) ชื่อไฟล์จะเป็น “รหัส.gs” หรือ “Code.gs” ไม่ต้องเปลี่ยนชื่อ

4

ตั้งรหัสลับ (ไม่บังคับ)
ถ้าอยากกันคนอื่นแอบเรียกใช้ ให้หาบรรทัด const TOKEN = ''; (อยู่ด้านบนของโค้ด) แล้วใส่รหัสระหว่างเครื่องหมาย ' ' เช่น const TOKEN = 'abc123'; กดบันทึกอีกครั้ง และใส่รหัสเดียวกันในช่อง TOKEN ของโปรแกรม ถ้าไม่ต้องการ ปล่อยว่างไว้ทั้งสองที่

5

สร้างการทำให้ใช้งานได้ (Deploy)
กดปุ่มสีน้ำเงิน การทำให้ใช้งานได้ มุมขวาบน (จุด 1) แล้วเลือก การทำให้ใช้งานได้รายการใหม่

ในหน้าต่างที่เปิดขึ้น ตั้งค่าตามรูป: จุด 1 กดไอคอนเฟือง ⚙ ข้างคำว่า “เลือกประเภท” แล้วเลือก เว็บแอป · จุด 2 “ดำเนินการในฐานะ” = ฉัน · จุด 3 “ผู้ที่มีสิทธิ์เข้าถึง” = ทุกคน (ข้อนี้สำคัญ ถ้าไม่ใช่ “ทุกคน” โปรแกรมจะเชื่อมต่อไม่ได้) · จุด 4 กด ทำให้ใช้งานได้

6

อนุญาตสิทธิ์ (ครั้งแรกครั้งเดียว)
ถ้ามีหน้าขอสิทธิ์ ให้กด ให้สิทธิ์เข้าถึง → เลือกบัญชี Google ของคุณ → กด ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต หน้าจอเตือนนี้เป็นเรื่องปกติ เพราะโค้ดนี้คุณสร้างเอง ยังไม่ได้ส่งให้ Google ตรวจ

7

คัดลอก Web app URL
หลังกด Deploy จะมีหน้าต่างสรุป (หรือเปิดได้จาก การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้) กด คัดลอก ใต้หัวข้อ เว็บแอป (จุด 1) ลิงก์ที่ถูกต้องต้อง ลงท้ายด้วย /exec อย่าใช้ลิงก์ในหัวข้อ “ไลบรารี”

8

วางในโปรแกรมและทดสอบ
เปิด ตั้งค่า (เมนูซ้ายมือ หรือแถบล่างบนมือถือ) วางลิงก์ในช่อง Web app URL (จุด 1) กด ทดสอบ (จุด 2) ถ้าขึ้นข้อความสีเขียว “เชื่อมต่อสำเร็จ ✓” ให้กด บันทึก (จุด 3) ถ้าตั้งรหัสลับในขั้นตอนที่ 4 ให้กรอกในช่อง TOKEN ด้วย จากนั้นโปรแกรมจะซิงค์ข้อมูลให้เอง และสร้างแท็บ PM_Data ในชีต

เมื่อแก้โค้ดภายหลัง ต้อง Deploy เป็นเวอร์ชันใหม่: การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ ✏️ → เวอร์ชัน “เวอร์ชันใหม่” → ทำให้ใช้งานได้ ลิงก์ /exec เดิมจะยังใช้ต่อได้ · ถ้าติดปัญหา ดูหัวข้อ 10

10. ข้อควรรู้ และการแก้ปัญหา
  • ถ้าไม่ได้เชื่อม Google Sheet ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ การล้างข้อมูลเบราว์เซอร์ ใช้โหมดไม่ระบุตัวตน หรือเปลี่ยนเครื่อง ข้อมูลอาจหาย ควรกด “บันทึก” ลงไฟล์ Excel สำรองไว้เป็นระยะ
  • ทดสอบการเชื่อมต่อไม่ผ่าน: ตรวจว่าใช้ลิงก์ที่ลงท้าย /exec และ Deploy เป็น “ทุกคน (Anyone)” แล้ว ถ้าขึ้น “รหัสลับไม่ตรง” ให้ตรวจ TOKEN ทั้งในโค้ดและในโปรแกรม
  • ป้าย ⚠ ไม่หาย: ตรวจอินเทอร์เน็ต ข้อมูลที่แก้ไว้ยังอยู่ในเครื่องและจะถูกส่งซ้ำอัตโนมัติ หรือกดป้ายสถานะเพื่อไปตรวจการตั้งค่า
  • ข้อมูลไม่ขึ้นบนเครื่องอื่น: รอ 1 นาที หรือกลับมาเปิดแท็บนี้ใหม่ ถ้ายังไม่ขึ้นให้กด “ดึงข้อมูลจากชีต” ในหน้าตั้งค่า (ระบบจะไม่โหลดทับขณะกำลังพิมพ์ในช่องหรือเปิดกล่องเลือกอยู่)
  • แก้โค้ด Code.gs แล้วไม่ทำงาน: ต้อง Deploy เวอร์ชันใหม่ตามขั้นตอนท้ายหัวข้อ 9
  • เปิดไฟล์ไม่ได้ “ไม่พบชีต”: ไฟล์ต้องเป็นฐานข้อมูลของโปรแกรมนี้ (มีชีต PM., PM. PLAN Y. และชีตรายเดือน “1 Jan.” ถึง “12 Dec.”)
11. ใช้งานบน iPhone / iPad
  1. เปิดหน้าเว็บด้วย Safari แตะปุ่ม แชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอนเปิดใช้เหมือนแอป
  2. Safari ไม่รองรับการบันทึกลงไฟล์เดิม การกด “บันทึก” จะดาวน์โหลดไฟล์ใหม่

ข้อควรระวัง: Safari กับไอคอนบนหน้าจอโฮมเก็บข้อมูลแยกกัน และ Safari อาจล้างข้อมูลของเว็บที่ไม่ได้เปิดใช้นานกว่า 7 วัน แนะนำให้ เชื่อมต่อ Google Sheet (หัวข้อ 8) เสมอ แล้วเครื่องที่ข้อมูลหายก็ดึงกลับจากชีตได้
